# OKX USDT 永续策略回测

新的回测页面与 Python 服务在 `backtest/`，无需 API Key 或第三方 Python 包。

## 启动

需要 Python 3.10+（已在 Python 3.12 验证）。在仓库根目录运行：

```sh
python -m backtest
```

在浏览器访问 `http://127.0.0.1:8000`。如果端口占用，可使用 `python -m backtest --port 8001`。

默认开仓日期为 **2026-01-01 至 2026-11-03**（含结束当天），可修改日期。合约范围留空会扫描本次 OKX 返回的所有 USDT 本位线性永续合约；建议先选少量币对验证网络，再扫描全部。不要填写 API Key。

页面可设置 **买入涨幅、止盈比例、止损比例**，单位均为百分比：填 `5` 表示 5%，不是 0.05%。默认分别为 **10 / 3 / 6**。三项均须大于 0，止损须小于 100%，最多支持 6 位小数；买入涨幅和止盈比例上限为 1,000,000%。止盈、止损相对于买入价计算，买入涨幅相对于当天 UTC+8 零点开盘价计算。每次回测的实际参数会保存到 JSON 和每笔交易的 CSV 中。修改参数后请重新运行回测；完整行情缓存仍可复用。

GitHub Pages 是静态托管，只能展示 `backtest/index.html` 的界面，**不能运行 Python 或执行回测**。当前工具需在本机运行，或另行部署后端。原落地页不受影响。

## 交易规则

- 每天按 **UTC+8 00:00** 日线开盘价重新设定基准，成交价首次严格超过所设买入涨幅时开多（默认 **10%**，即基准价的 **110%**）；每币对每天最多一笔。OKX `bar=1D` 对应 UTC+8，不能替换成 `1Dutc`。
- 每笔名义本金 **10,000 USDT**，数量按本金除以模拟买入价计算。暂不计交易费、资金费、滑点、数量步长、杠杆或资金上限。可以存在同币对跨天重叠持仓。
- 按设置的比例退出，默认相对买入价 **+3% 止盈成功**，**−6% 止损失败**。未退出则跨天持有，追踪到本次运行时最后完整分钟，不在结束日期强制平仓。
- 开仓日期的日线最高价只用于筛选候选，实际买入只由按时间排序的分钟线首次突破决定，不使用当日最高价选择入场时点。
- 使用成交价历史分钟 K 线，突破边界作为**估算**买入价；分钟开盘已超过边界则使用开盘价。价格跳空越过退出价时按开盘价退出。
- 时间为触发所在分钟（UTC+8），不是精确成交秒。边界成交价是假设，不保证真实订单能以该价格成交。
- 同一分钟触及止盈和止损，或者开仓分钟低点可能发生在买入前/后时，标为 **顺序不明**，不编造胜负、退出价或退出时间。
- 截止时仍未退出的交易标为 **持仓中**，不计为失败。数据缺失标为 **数据异常**，不能当作没有信号。

## 数据范围与限制

行情源：`https://www.okx.com/api/v5/public/instruments?instType=SWAP` 和 `/api/v5/market/history-candles`。只采用 `confirm=1` 的完整 K 线；以递减的 `after` 游标分页。先下载日线筛选，再读取候选日期和必要持仓日期的分钟线，完整连续数据保存到 `.backtest-cache/`，重复运行可复用。

### 下载与缓存加速

- **按本次参数筛选**：买入涨幅改为 5%，就为日内涨幅超过 5% 的日期读取分钟线；不会沿用默认 10% 的筛选结果。
- **持仓日排除**：仅当完整日线最高价严格低于本笔止盈价、最低价严格高于止损价时，跳过该持仓日的分钟下载。触及任一边界、缺少日线或当天尚未结束时，仍读取分钟线确认；不以日线推断先后顺序。每次修改参数都会重新判断。
- **断点续传**：每页已确认 K 线立即保存到 `.backtest-cache/candles/history.sqlite3`。取消或网络中断后重跑会复用已下载的部分，只补缺口；不完整区间仍不能当作完整数据。
- **范围复用**：新缓存按币对、周期和时间戳查询，修改日期范围时可复用重叠部分；每个任务还保留最多 24 个完整区间的内存缓存，减少重复解析。
- **兼容旧缓存**：旧版本的哈希名 JSON 文件保留不变。再次请求其原有币对/周期/起止范围时会自动读取，并导入新缓存以支持后续范围复用；尚未读取的旧文件不能自动用于任意重叠区间。
- 页面显示网络请求数和缓存复用次数，结果记录省去分钟下载的持仓日数量。首次下载仍受 OKX 接口限速和本地网络速度影响。

**当前合约列表可能遗漏已下架合约，因此不能宣称覆盖整个历史市场**。上市当天没有零点开盘基准则排除。历史数据的实际覆盖受 OKX 可用数据、地区限制和网络许可影响；日线或分钟缺口会显式报告。有错误时结果标为不完整。

全市场、长周期运行可能需要较长时间及较多磁盘空间。任务在后台执行，可查看进度或取消；取消后保留每页已下载的行情，但不将部分结果冒充完整回测。服务一次只运行一个任务，接口按请求间隔 150ms 限速，遇临时网络错误/限流会有界重试。

完成后可按日期、结果筛选，导出交易 CSV，或导出含参数、覆盖范围、错误及计算规则的 JSON。完整 JSON 同时保存到 `.backtest-cache/<运行ID>.json`；进程重启后仍可从磁盘读取历史导出文件。无交易日期表示没有触发信号的前提是当日数据完整。

## 测试

```sh
python -m unittest discover -s tests -v
```

测试使用明确标注的合成 K 线，验证规则与服务行为，不代表已获取真实市场数据或已经完成该历史区间的回测。

## 云环境

需要允许 HTTPS 访问 `www.okx.com`，保留平台代理和 TLS 校验。应用只绑定本地环回地址，不把管理接口暴露公网。每个云任务已有独立环境，使用现有 checkout，无需创建 Git worktree。云端进程不会随快照恢复，需要重新运行 `python -m backtest`。
